# DropSauce extensions

Extension store for [DropSauce](https://github.com/HuzaifaKhalid1311/DropSauce) (Mihon format, lib 1.6) with 128 extensions.

## Add to DropSauce

**Extension stores → Add store**, then paste:

```
https://raw.githubusercontent.com/fvgs0495reijogp/random-repo/main/index.min.json
```

If you installed any of these from the Keiyoushi store, uninstall those first: these are signed with a different
key, so Android won't replace them in place.

Most extensions are built from [Keiyoushi's source](https://github.com/keiyoushi/extensions-source) (Apache-2.0)
with the same package names and source IDs, so existing library entries keep working.
